# GitHub Pages: Арава ВНАУ

Це статична сторінка завантаження для репозиторію `letimaks/Polymath`.

## Розміщення

1. Скопіюй папку `arava-vnau` у корінь репозиторію `Polymath`.
2. Переконайся, що в репозиторії опубліковано GitHub Pages із кореня гілки `main` (або перенеси папку до фактичної директорії Pages).
3. Сторінка відкриватиметься за адресою `https://letimaks.github.io/Polymath/arava-vnau/`.

## Публікація ZIP

1. Відкрий GitHub → Releases → Draft a new release.
2. Створи тег `v2.2.7`.
3. Додай ZIP з ім'ям `AravaVNAU_2_2_7.zip` як Release asset.
4. Опублікуй реліз.

Сторінка автоматично читає останній GitHub Release через публічний GitHub API і показує кнопку завантаження відповідного ZIP-файлу. При наступній публікації релізу зі схожою назвою ZIP автоматично буде показано нову версію.

## Автоматичне оновлення Chrome

GitHub Pages/Release забезпечує автоматичне оновлення інформації на сторінці та посилання на новий ZIP, але не встановлює нову версію в Chrome автоматично. Для звичайного Windows Chrome використовуйте Chrome Web Store: опублікуйте розширення там, після чого користувачі отримуватимуть оновлення через штатний механізм Chrome. Самостійний хостинг CRX-оновлень на Windows/macOS підтримується лише в керованих корпоративних середовищах.
