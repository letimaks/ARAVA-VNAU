# Арава ВНАУ — сторінка розширення

Сайт: https://letimaks.github.io/ARAVA-VNAU/

Репозиторій: https://github.com/letimaks/ARAVA-VNAU

## Публікація ZIP
1. Відкрий Releases → Draft a new release.
2. Створи тег v2.2.7.
3. Додай файл AravaVNAU_2_2_7.zip до assets релізу.
4. Опублікуй реліз.

Сторінка автоматично перевіряє останній реліз саме цього репозиторію та показує посилання на ZIP.

## Встановлення одним натисканням
Для звичайного Chrome на Windows вебсторінка не може інсталювати локальний ZIP напряму. ZIP можна встановити через chrome://extensions → Developer mode → Load unpacked. Однокнопкове встановлення та звичайні автоматичні оновлення доступні після публікації розширення в Chrome Web Store. Після появи картки магазину впиши її повний URL у CHROME_STORE_URL в arava-vnau/assets/app.js.
