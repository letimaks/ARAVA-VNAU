Як додати в Chrome

ZIP-версія встановлюється вручну. Після виходу нового релізу її потрібно оновити через цю сторінку.

  1. 01
    Завантаж ZIPНатисни кнопку завантаження вище та розпакуй архів.
  2. 02
    Відкрий сторінку розширеньПерейди на chrome://extensions і ввімкни «Режим розробника».
  3. 03
    Завантаж розпаковану папкуНатисни «Завантажити розпаковане» та вибери папку, де знаходиться manifest.json.
  4. 04
    Оновлюй через новий ZIPЗавантаж новий реліз, заміни папку та перезавантаж розширення.
Про автоматичні оновлення Chrome

GitHub-сторінка може автоматично знаходити новий реліз, але не може самостійно замінити файли розпакованого розширення. Для автоматичного оновлення звичайного користувацького Chrome розширення потрібно опублікувати в Chrome Web Store.
